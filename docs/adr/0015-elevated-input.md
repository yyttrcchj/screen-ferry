# 0015. Windows 管理员窗口的输入

状态：已采纳

日期：2026-11-08

## 背景

Windows 的用户界面特权隔离（UIPI）按进程完整性级别限制输入：

- 普通权限（中等完整性）的后台可以用低级键鼠钩子捕获普通窗口的输入，但管理员窗口在前台时，
  钩子收不到那部分输入。
- 普通权限的 `SendInput` 不能把键鼠事件注入管理员窗口。被控端会表现为鼠标停在原地、键盘没有响应；
  把管理员窗口最小化或关闭后，普通窗口恢复正常。

Everything、Satelite 等软件可以由用户选择“以管理员身份运行”，因此不能要求用户关闭这些软件，
也不能让 ScreenFerry 只支持普通窗口。可行的系统级方案有：

| 方案 | 结果 |
|---|---|
| 程序清单申请 `requireAdministrator` | 每次启动、包括只用命令行时都弹 UAC，权限过大 |
| 打开 `uiAccess` | 可以操作管理员窗口，但要求程序签名并安装在受保护目录；本项目不签名，无法使用 |
| 后台常驻进程以管理员权限运行 | 能捕获和注入管理员窗口；需要处理 UAC 和开机自启 |
| 单独做高权限服务 | 边界最好，但当前版本没有服务，工作量和安装要求都更高 |

本决策采用第三种。只把需要键鼠权限的后台提升；设置界面和命令行子命令仍然普通权限运行。

## 决策

### 常驻后台

- `screenferry.exe` 的程序清单保持 `asInvoker` 和 `uiAccess=false`，避免命令行子命令无条件弹 UAC。
- 以常驻模式启动时，后台先查询自己的令牌。不是管理员时，用 `ShellExecuteExW` 的 `runas` 动词以
  管理员身份重新启动自己，原来的普通权限进程退出。
- 重新启动的命令行带内部参数 `--elevation-attempt`。提升后的进程如果仍不是管理员（例如用户取消、
  或系统策略不允许），就显示一次错误并退出，不会无限弹 UAC。
- 已经有一份管理员后台在运行时，新启动的普通权限进程只经本机通信请它打开设置界面，不再弹 UAC。
- 已经登记了计划任务时，重新启动改用 `schtasks /Run`：任务计划程序按任务里登记的“最高权限”
  启动它，同样不弹 UAC。任务不存在、被禁用或者 20 秒内没有接管时才退回 `runas`。
- 发现旧版本留下的普通权限后台时，管理员进程先请它正常退出，再接管键鼠；旧进程不支持退出命令时
  不强行抢控制权，安装程序负责结束旧进程。
- 注入失败后，只有在“当前后台不是管理员、前台窗口属于管理员进程”时才报告权限不足；后台已经是
  管理员时，其他 `SendInput` 错误仍按系统错误记录，避免误导排查方向。

### 开机自启

- Windows 的开机自启不再写 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，改为当前用户
  “登录时运行、最高权限”的任务计划程序任务：
  `schtasks /Create /SC ONLOGON /RL HIGHEST /IT`。
- 计划任务在登录时直接获得完整管理员令牌，不弹 UAC；`/IT` 保证任务在交互式用户会话中运行。
- 启动时如果发现旧版本留下的 Run 登记，就创建计划任务并删除旧值；任务创建失败时保留旧值，不悄悄
  关掉用户的开机自启。
- 安装程序升级时也执行同样的迁移；卸载时删除计划任务和旧 Run 值。

### 设置界面和命令行

- 设置界面由管理员后台通过资源管理器启动。资源管理器以普通权限运行，因此设置界面不会继承后台的
  管理员令牌，仍按普通程序打开。
- `serve`、`connect`、`peers`、`quit` 等命令行子命令不自动提升。它们用于调试；需要在管理员窗口上
  调试时，用户从管理员终端启动。

## 边界

- 管理员后台可以操作管理员应用，但不能操作 UAC 的安全桌面，也不能远程发送 `Ctrl+Alt+Del`。这些是
  Windows 的安全边界，不能通过提升普通进程绕过。
- 后台的整个进程（包括网络、剪贴板和文件传输）都拥有管理员权限。当前版本的进程边界已经固定；
  以后要降低权限面，应把输入能力拆到 `screenferry-service`，由服务只接受经过认证的本地请求。
- 用安装包装好、并开着“开机自动启动”时，安装包、登录和双击启动都不会弹 UAC：安装包本身以管理员
  运行，登录走计划任务，双击启动交给同一个任务。只有还没登记任务时（直接运行开发版本，或者关掉了
  开机自动启动）才会弹一次。UAC 提示框在安全桌面上，从另一台电脑控制这台时点不到，因此要尽量减少
  弹出的次数。
- 用户拒绝提权时，后台不启动，管理员窗口继续无法被控制，这是明确失败而不是静默失灵。
